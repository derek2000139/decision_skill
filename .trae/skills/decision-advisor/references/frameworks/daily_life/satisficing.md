# 满意解理论 Satisficing Theory

## 元信息

| 项目 | 内容 |
|-----|-----|
| 提出者 | Herbert A. Simon（赫伯特·西蒙） |
| 出处 | Administrative Behavior (1947); Models of Man (1957) |
| 诺贝尔奖 | 1978年诺贝尔经济学奖 |
| 适用场景 | 日常低复杂度决策，信息不完整，时间有限 |
| 核心思想 | 人类是有限理性的，不追求最优解，而是追求"足够好"的满意解 |

## 理论背景

Simon 批判了传统经济学的"完全理性人"假设。
真实决策中，人类受到认知能力、时间、信息的限制，
实际上执行的是"有限理性"（Bounded Rationality）策略：
设定一个满意阈值，找到第一个超过阈值的选项即停止搜索。

## 决策步骤

Step 1: 明确"足够好"的标准
  → 问：什么样的结果你可以接受？
  → 不是"最好的"，而是"满足条件的"

Step 2: 列出选项
  → 不需要穷举所有选项
  → 列出当前能想到的 3-5 个即可

Step 3: 依次检验
  → 每个选项是否达到满意阈值？
  → 第一个达标的选项即为决策结果

Step 4: 执行，不回头
  → 满意解的关键：做出选择后停止比较

## 交互问题模板

Q1: 对于这个决定，你的底线要求是什么？
    （不是"最好的"，而是"可以接受的最低标准"）

Q2: 你目前能想到的选项有哪些？
    （列出3-5个即可，不用穷举）

Q3: 时间要求是什么？
    （你有多长时间做这个决定？）

## 输出格式

```
┌─────────────────────────────────────┐
│         满意解决策卡                 │
├─────────────────────────────────────┤
│ 决策问题：今天中午吃什么？           │
│                                     │
│ 满意阈值：                          │
│  ✓ 步行10分钟内                     │
│  ✓ 价格 < 50元                      │
│  ✓ 不是昨天吃过的                   │
│                                     │
│ 选项检验：                          │
│  选项A：沙县小吃  ✓✓✓  → 满意解！  │
│  选项B：日料     ✗（价格）          │
│                                     │
│ 决策结果：选项A                     │
│ 执行建议：直接出发，停止比较         │
└─────────────────────────────────────┘
```

## 适用边界

**适合用满意解的情况**：
- 决策可逆（吃饭、购物、日常安排）
- 时间有限
- 信息不完整
- 过度比较会带来"选择悖论"（Barry Schwartz, The Paradox of Choice, 2004）

**不适合满意解的情况**：
- 不可逆的重大决策（职业、婚姻、战略）
- 需要最优化的专业决策
