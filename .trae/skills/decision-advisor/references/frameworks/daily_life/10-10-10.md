# 10-10-10 决策法

## 元信息

| 项目 | 内容 |
|-----|-----|
| 提出者 | Suzy Welch（苏西·韦尔奇） |
| 出处 | 10-10-10: A Life-Transforming Idea (2009) |
| 适用场景 | 情绪化决策、短视决策、日常到中等复杂度 |
| 核心思想 | 从三个时间维度检验决策，克服短期情绪对判断的扭曲 |

## 三个时间维度

10分钟后：这个决定的即时感受是什么？
10个月后：这个决定的中期影响是什么？
10年后：这个决定对长期人生轨迹的影响是什么？

## 理论支撑

与 Kahneman 的"体验自我 vs 记忆自我"理论呼应：
- 10分钟 → 体验自我（当下感受）
- 10年   → 记忆自我（长期叙事）

两者冲突时，优先尊重长期叙事。

## 交互问题模板

Q1: 你面临的决定是什么？请简要描述。

Q2: 选项A是什么？

Q3: 选项B是什么？

Q4: 如果选择选项A，10分钟后你的感受是什么？
    （开心？后悔？焦虑？释然？）

Q5: 如果选择选项B，10分钟后你的感受是什么？

Q6: 选择选项A，10个月后你的生活/工作会有什么变化？

Q7: 选择选项B，10个月后会有什么变化？

Q8: 10年后回头看，选择了选项A的你会是什么状态？
    （与你理想中的自己相比，是否一致？）

Q9: 10年后回头看，选择了选项B的你会是什么状态？

## 输出格式

```
┌────────────────────────────────────────────────────┐
│              10-10-10 时间维度分析                  │
├──────────┬─────────────────────────────────────────┤
│ 时间维度 │ 选项A：继续现在的工作                   │
├──────────┼─────────────────────────────────────────┤
│ 10分钟后 │ 感到安心，不用面对未知的风险             │
│ 10个月后 │ 技能停滞，薪资没有增长，轻微后悔        │
│ 10年后   │ 可能错过了转型窗口，职业天花板已现       │
├──────────┼─────────────────────────────────────────┤
│ 时间维度 │ 选项B：跳槽到新公司                     │
├──────────┼─────────────────────────────────────────┤
│ 10分钟后 │ 焦虑，不确定感强                        │
│ 10个月后 │ 适应期结束，接触了新技能和人脉           │
│ 10年后   │ 更宽的职业路径，与理想自我更接近         │
└──────────┴─────────────────────────────────────────┘

综合建议：长期维度支持选项B，短期焦虑是正常的适应成本。
```
